🚀 极速上手

无需电脑，设备内自主完成配对与激活

仅需 4 步，利用 Android 原生无线调试机制，建立自主特权通信闭环。

1

开启无线调试

打开系统「设置」➔「开发者选项」➔「无线调试」，打开总开关，确保连接 Wi-Fi 或本机热点。

2

获取 6 位配对码

在系统无线调试设置中，点击「使用配对码配对设备」，界面将弹出 6 位数字码与配对端口。

3

通知栏一键填入

切换回本应用点「开始配对」，下拉通知栏，直接在常驻通知的输入框内填入 6 位码并发送。

4

自动激活与就绪

底层完成 TLS 1.3 握手并拉起特权代理（Shell uid 2000），仪表盘转为「已就绪」，即可静默安装。

🔒

单机私钥凭据安全承诺

用于配对认证的 2048 位 RSA 秘钥由应用在本地安全生成，存储于沙箱私有目录 filesDir/adb_key.pk8，并在 Android 备份规则中显式排除。密钥绝不上传云端，亦不离开本机，从底层保障设备凭据安全。

🏗️ 系统架构

三层解耦与 4 字节大端长度前缀协议

客户端与特权执行端严格分离。业务层在 Rust installer-core 实现 host 端全量单测；特权代理 broker-server 基于 Tokio 运行时在 Shell (uid 2000) 独立运行。

  • ✓ 16KB 页对齐： 严格遵循 Google 最新规范，四 ABI 原生动态库全面对齐 16KB 内存页。
  • ✓ SPAKE2 握手： Edwards25519 曲线强鉴权，6 位动态码即时派生会话密钥。

💡 常见问题

解答你的所有疑问

关于特权、安全、配对与稳定性的详细说明。

手机重启后特权服务需要重新配对吗？
不需要重新配对！只要没有清除应用数据，本地 RSA 密钥与系统配对状态始终有效。手机重启后只需确保无线调试处于开启状态，点击应用内的「激活服务」或由内置的 Keeper/BrokerReviver 自动嗅探端口重新拉起特权代理即可，全程无需再次输入 6 位配对码。
为什么本软件不需要电脑就能完成无线调试自启？
Android 11+ 原生引入了无线调试与配对协议规范。本软件内置了一套纯 Rust 实现的完整的无线调试协议栈（mDNS 组播服务发现 + Edwards25519 SPAKE2 密钥交换 + TLS 1.3 证书通道 + ADB 通信协议），应用自身即可作为 ADB 客户端与本机 adbd 握手通信，从而彻底摆脱对电脑和数据线的依赖。
开启「成功后删除安装包」会不会误删我手机里的其他文件？
绝不会。在暂存安装包阶段，系统已采集并计算了真实文件的物理体积与 SHA-256 内容哈希。在执行五级清理的任何一级之前，都会强制校验目标文件的大小与哈希，核验不通过宁可放弃删除也绝对不会误删同名文件；所有 Shell 命令均通过位置参数化安全传递，杜绝命令注入。
是否需要 Root 或 Shizuku、Xposed 等第三方框架？
完全不需要。本软件拥有完全自主的 Broker 后台进程（运行于 Shell uid 2000 边界下），不依赖任何 Root 提权，亦不依赖 Shizuku 或任何第三方守护进程，是一个自包含、零外部依赖的完全独立套件。
